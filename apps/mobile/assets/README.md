# assets/

Images de l'application. **Provisoires** : elles sont redessinées en vectoriel d'après le logo validé par le groupe
(`docs/design/logo/`). Le ticket L7-04 les remplacera par les fichiers finaux du designer.

| Fichier             | Usage                                                  | Format                 |
| ------------------- | ------------------------------------------------------ | ---------------------- |
| `icon.png`          | Icône de l'application (iOS, général)                  | 1024×1024, sans alpha  |
| `adaptive-icon.png` | Premier plan de l'icône adaptative Android             | 1024×1024, transparent |
| `splash.png`        | Écran de lancement (fond blanc défini dans app.config) | 1024×1024, transparent |
| `favicon.png`       | Onglet du navigateur (version web)                     | 196×196, transparent   |

Polices Manrope et Inter à ajouter via `expo-font` (ticket L7-05).
